# Adversarial cross-review

Review the assigned anonymous report using the locked sources and rubric.
You have not been given the auditor's conclusions. Check all target IDs exactly
once in checked_targets, including summary and limitations. Return the review
schema. Find substantive contradictions, missing evidence, scope errors and
interpretations. Give each objection a unique ID, severity, concrete reason,
source excerpts where available, and what would resolve it. Do not invent
objections to fill a quota or infer authorship. Empty findings are allowed.

The imported multi-reviewer skill supplies guidance on finding organization and
severity. Apply the assigned research schema and major/minor rubric here, rather
than its example code-review template or code-specific severity rules.
